# 📊 Excel Sales Report Dashboard

## 📌 Project Overview
An interactive and visual Excel Sales Dashboard designed to analyze sales performance, regional distributions, and key business metrics. This project transforms raw sales data into actionable insights through clear data visualization techniques.

## 🚀 Key Features
* **Key Metrics (KPIs):** Total Sales, Total Revenue, Units Sold, and Average Order Value.
* **Interactive Filters:** Dynamic Slicers for quick filtering by Date, Region, Product Category, and Sales Representative.
* **Visualizations:** Bar/Column charts for product performance, Line graphs for sales trends over time, and Pie charts for market share distribution.
* **Automated Data Processing:** Cleaned raw data using Excel formulas and structured Pivot Tables.

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** Data Cleaning, Pivot Tables, Pivot Charts, Formulas (VLOOKUP/XLOOKUP, SUMIFS), Slicers, and Conditional Formatting.
